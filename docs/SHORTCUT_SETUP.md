# iPhone 快捷指令安装与配置

## 前提

- iPhone 已安装高德地图。
- Safari 能访问你的后端 `https://域名/health`。
- 健康检查返回 `"configured": true`。

## 安装

1. 在 GitHub 仓库打开 `shortcut/漫步导航 分享版.shortcut` 并下载文件。
2. 在 iPhone“文件”App中点开该文件。
3. 系统显示快捷指令内容后选择添加。

该文件使用 Apple 的“导出给任何人”格式签名，导入时可能需要联网让 Apple 验证。

## 四个导入问题怎么填

快捷指令有两个请求：正常解析，以及服务器抓取小红书失败后的“手机正文重试”。Apple 的导入问题绑定到具体操作，因此同样的配置需要填写两遍。

1. 主请求完整地址：`https://api.example.com/parse`
2. 主请求头：保留 `Content-Type: application/json`，把 Authorization 改成 `Bearer 你的ROUTESNAP_ACCESS_TOKEN`
3. 重试请求完整地址：与第 1 项完全相同
4. 重试请求头：与第 2 项完全相同

注意：

- 地址必须包含最后的 `/parse`。
- `Bearer` 后有一个半角空格。
- 这里填的是 `ROUTESNAP_ACCESS_TOKEN`，不是 DeepSeek Key 或高德 Key。
- 两次 URL 和两次 Authorization 必须完全相同。

## 第一次测试

先复制这段不依赖小红书抓取的文本：

```text
路线：曲院风荷 → 杭州花圃 → 乌龟潭
```

运行“漫步导航 分享版”。正确结果是打开高德地图，并带入步行路线。

再复制一条小红书分享口令并运行快捷指令。正常流程是：

1. 快捷指令把剪贴板文本交给服务器。
2. 服务器优先查持久化缓存，再尝试获取小红书正文。
3. 正文抓取成功后，提取地点、调用高德定位并返回路线。
4. 如果服务器明确返回 `xhs_fetch_failed`，快捷指令才尝试用 iPhone 网络获取页面正文并再次提交。
5. 两种方式都失败时显示明确错误，不会用截断标题猜路线。

## 分享给别人

每个使用者都应该部署自己的后端并填写自己的 Token。不要把你已经配置好真实服务器 Token 的快捷指令再次导出到公共仓库。
